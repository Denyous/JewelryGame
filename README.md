# Jewelry Store

**Jewelry Store** is a 2D shop management simulation game developed with Unity and C#.

In this game, players manage their own jewelry store, interact with customers, and build their business by buying and selling jewelry. Players evaluate customer offers, manage their inventory, and make economic decisions to grow their store.

##  Game Overview

The main objective is to successfully manage a jewelry store by handling customer interactions and making profitable transactions.

- **Customer Interactions:** Interact with customers who visit the store to buy or sell jewelry.
- **Buying & Selling System:** Purchase jewelry from customers and sell items to potential buyers.
- **Business Management:** Manage daily operations and make decisions to maintain profitability.
- **Daily Cycle:** Experience a day-based gameplay loop that structures the store's business activities.
- **Economy Management:** Track money, transactions, and the store's financial state.
- **Inventory Management:** Organize and manage the jewelry available in the store.

##  Technical Features & Systems

The project includes several gameplay systems and software architecture concepts implemented using Unity and C#.

### Gameplay Systems

- **Customer System:** Manages customer interactions and buying/selling behaviors.
- **Day Cycle System:** Controls the daily gameplay progression and shop operations.
- **Economy System:** Handles the store's money, transactions, and financial management.
- **Inventory System:** Manages jewelry items, item storage, and inventory operations.
- **UI System:** Provides interactive user interfaces for shop management, customer interactions, and gameplay information.

### Software Architecture & Design Patterns

- **MVP (Model-View-Presenter):** Separates data, UI presentation, and application logic to improve maintainability and code organization.
- **Event-Driven Architecture:** Uses events and delegates for communication between gameplay systems and UI components.
- **ScriptableObjects:** Provides reusable, data-driven definitions for jewelry items and game data.
- **Singleton Pattern:** Provides centralized access to shared managers and core gameplay systems.
- **Object-Oriented Programming:** Applies object-oriented principles to build modular and maintainable gameplay systems.
